# Security Policy

## Reporting a vulnerability

Please do not report security problems in public issues.

Report them privately through GitHub instead:

1. Open the [Security tab](https://github.com/ChadProbert/celerity/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem and the steps to reproduce it.

The report stays private between you and the maintainer until a fix is ready.

## Supported versions

Only the latest version of Celerity receives security fixes.
